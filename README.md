# Respirator Guide

A simple mask picker, a gallery of every mask type, and a full comparison.

- Picker: https://sofyaleb.github.io/respirator-guide/
- All masks: https://sofyaleb.github.io/respirator-guide/masks.html
- Details: https://sofyaleb.github.io/respirator-guide/details.html

`shared.js` holds the mask data and the face drawing used by the picker and the gallery.
